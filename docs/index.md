# QuickLearnKit

**QuickLearnKit** is a *learning-first machine learning utilities library* designed to simplify common workflows while preserving full control for advanced users.

> *Remove mechanical friction so students can focus on concepts, not syntax.*

---

## Installation

```bash
pip install quicklearnkit
```

---

## Overview

QuickLearnKit provides structured, readable tools for:

- Simplified model imports  
- Dataset sampling and utilities  
- Train–test splitting  
- Probabilistic, group-aware imputation  
- Teaching-friendly visualization wrappers  
- Notebook → Script pipeline compilation

## Design Philosophy

QuickLearnKit balances:

**Beginner simplicity × Advanced control**

It supports:

- Learning  
- Experimentation  
- Structured building  

—without introducing heavy workflow orchestration systems.
